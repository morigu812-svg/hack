# CYBER//BREACH

黒×ネオンのリアルタイム・ハッキングシミュレーター試作版。架空のネットワーク内で、探索 → 解析 → 侵入 → VAULT回収を4分以内に完了します。外部システムへの攻撃や実コマンドの実行は行いません。

## 起動

GitHub Pagesでルートを公開するか、ローカルで `npm run dev` を実行して http://localhost:8000 を開いてください。ビルド・APIキー・有料サービスは不要です。ES ModulesのためHTMLの直接ファイル起動ではなくHTTPサーバーを使用してください。

## 実装済み

- ソロ / CPU対戦 / 同一端末の2人対戦 / 同一端末の2人協力
- タップ・クリックとコマンドの両方で同じ操作が可能
- ネットワーク経路、3種の脆弱性、探索・解析・侵入・回収
- エネルギー管理、追跡、冷却・回復、3段階の難易度
- コマンド履歴（上下キー）、操作ガイド、レスポンシブ表示
- 協力では担当ごとの2つの並行作業、対戦では先に回収した側が勝利

## コマンド

`scan relay` / `analyze relay` / `tool cipher` / `breach relay` / `select vault` / `extract` / `cool` / `recover` / `status` / `help`

ツールは `cipher`・`inject`・`overflow`。弱点は毎回ランダムです。CPUは同じルールとリソースで作動します。進行状況はメモリ内のみで、再読込時にリセットされます。localStorageは使用しません。

## 現在の範囲と次の段階

オンライン対戦・協力、アカウント、サーバー保存は未実装です。2人モードは同一画面での操作に対応しています。次の開発ではルーム作成、サーバー側の状態検証、切断復帰を導入し、オンライン通信を追加できます。

ファイル構成：`engine.js`（ルール）、`app.js`（表示・入力・CPU）、`style.css`（画面）、`index.html`（エントリ）。ルールの検証は `npm test`。
