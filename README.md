# CYBER//BREACH — PROJECT NIGHTGLASS

ルートページを、ファイルの手掛かりを読み解きながら仮想ネットワークへ潜入する端末ゲームに更新しました。

## NIGHTGLASS の遊び方

1. 「作戦開始」で端末を起動し、右側の `briefing.txt` と `handoff.eml` を読む。
2. `scan` で次の接続先を発見。左側の端末ボタンか `connect gateway` で接続。
3. ファイルで見つけた認証情報を `login USER PASSWORD` または認証フォームへ入力。
4. メール、アクセスログ、マニフェストを調べ、Base64トークンと分割されたパスワードを解読。
5. VAULTへ入り、`decrypt evidence.enc KEY` → `download evidence.json` → `disconnect` で脱出。

認証情報は作戦ごとに変化します。制限時間は12分。認証失敗・定期監視・作業中の通信で追跡率が上昇し、100%になると失敗します。`route quiet` は低速・低リスク、`route fast` は高速・高リスク。`cover` で追跡率を下げ、`abort` で処理を中止できます。

英語の通信ログが毎秒約5行流れます。重要ログへの絞り込みと自動スクロールの停止、段階ごとのヒント、コマンド履歴、タップ操作を用意しています。

端末、IP、アカウント、証拠ファイルはすべてゲーム内の仮想データです。外部ホストへ接続しません。`download` もゲーム内のメモリへの回収を表します。ページ再読み込みで進行はリセットされます。

新しい潜入ミッションはソロです。以前のソロ・CPU対戦・同一端末の対戦／協力モードは画面右上の「旧モード」（`classic.html`）で利用できます。オンライン通信は未実装です。

新しいファイル：`mission.js`（潜入ルール・ファイル・仮想ネットワーク）、`operation.js`（画面と入力）、`operation.css`（端末画面）。

起動：`npm run dev`、テスト：`npm test`。APIキー・ビルド・有料サービスは不要です。GitHub Pagesではルートを配信してください。

## 旧プロトタイプの説明

# CYBER//BREACH

黒×ネオンのリアルタイム・ハッキングシミュレーター試作版。架空のネットワーク内で、探索 → 解析 → 侵入 → VAULT回収を4分以内に完了します。外部システムへの攻撃や実コマンドの実行は行いません。

## 起動

GitHub Pagesでルートを公開するか、ローカルで `npm run dev` を実行して http://localhost:8000 を開いてください。ビルド・APIキー・有料サービスは不要です。ES ModulesのためHTMLの直接ファイル起動ではなくHTTPサーバーを使用してください。

## 実装済み

- ソロ / CPU対戦 / 同一端末の2人対戦 / 同一端末の2人協力
- タップ・クリックとコマンドの両方で同じ操作が可能
- ネットワーク経路、3種の脆弱性、探索・解析・侵入・回収
- エネルギー管理、追跡、冷却・回復、3段階の難易度
- コマンド履歴（上下キー）、操作ガイド、レスポンシブ表示
- 協力では担当ごとの2つの並行作業、対戦では先に回収した側が勝利

## コマンド

`scan relay` / `analyze relay` / `tool cipher` / `breach relay` / `select vault` / `extract` / `cool` / `recover` / `status` / `help`

ツールは `cipher`・`inject`・`overflow`。弱点は毎回ランダムです。CPUは同じルールとリソースで作動します。進行状況はメモリ内のみで、再読込時にリセットされます。localStorageは使用しません。

## 現在の範囲と次の段階

オンライン対戦・協力、アカウント、サーバー保存は未実装です。2人モードは同一画面での操作に対応しています。次の開発ではルーム作成、サーバー側の状態検証、切断復帰を導入し、オンライン通信を追加できます。

ファイル構成：`engine.js`（ルール）、`app.js`（表示・入力・CPU）、`style.css`（画面）、`index.html`（エントリ）。ルールの検証は `npm test`。
